# 사장님 날짜 확인 수집용 데이터베이스 검토 (Supabase)

작성일 2026-10-28 · 무료 플랜 수치는 제3자 글 기준이라 [공식 요금 페이지](https://supabase.com/pricing)에서 재확인 필요

## 1. 왜 필요한가
- 나이스 졸업일이 실제와 다른 경우가 있음 (예: 과천고 나이스 12/1, 학교 일정표 12/15).
- 사장님들이 학교 공지로 확인한 날짜를 모으면 "N명이 확인" 표시로 보정 가능.
- 지금 사이트는 서버가 없어 입력이 각자 폰에만 저장됨 → **수집하려면 저장소가 필요**.
- GitHub만으로는 사용자가 직접 쓸 수 없음.

## 2. 무료 플랜 (Supabase)
| 항목 | 한도 | 우리 서비스 |
|---|---|---|
| DB 용량 | 500MB | 충분 (기록 1건 수십 바이트) |
| 월 전송량 | 5GB | 충분 (학교 데이터는 GitHub에서 전송) |
| 월 활성 사용자 | 5만 명 | 익명 입력이라 해당 없음 |
| 무료 프로젝트 | 2개 | 1개 사용 |
| 광고 | 없음 | - |

## 3. 검토할 내용
1. **7일 무활동 시 자동 일시정지** → 주 1회 GitHub Actions에서 가벼운 요청을 보내 방지.
2. **무료는 자동 백업 없음** → 주 1회 백업 파일 생성·보관.
3. **한도 초과·실사용자 증가 시 Pro 전환**(월 약 25달러대) 필요.
4. **약관**: 상업적 사용 조건 직접 확인.
5. **악용 방지**: 기기당 하루 입력 제한, 한 기기=한 표, 3기기 이상 같은 날짜일 때만 표시.
6. **개인정보**: 익명 번호만 저장(이름·연락처·위치 저장 안 함), 안내 문구와 약관 정리.
7. **표시 원칙**: 나이스 날짜를 덮어쓰지 않고 "나이스 12/1 · 사장님 5명이 12/15로 확인"처럼 별도 표시.

## 4. 결정
- 지금은 **보류**. 먼저 의심 표시·날짜 변경 알림을 만들고 사장님 반응 확인.
- 반응이 좋으면 Supabase 계정을 만들고 수집 도입.
