# 대학 학사일정 공개 방식 조사 (표본 11곳)

조사일 2026-10-28 · 목적: 대학 학위수여식 날짜를 자동으로 모을 수 있는지, 범위를 어디까지 잡을지 판단

## 1. 결과 요약
- **공통 형식·캘린더 피드(iCal/구글캘린더 구독)는 한 곳도 없었어요.** 대학 전체를 한 번에 가져올 표준 데이터는 이번 표본에서 확인되지 않았어요.
- 대신 **접속된 8곳 중 7곳이 2027년 2월 학위수여식 날짜를 이미 텍스트로 공개**하고 있어요. 1년 치 학사일정을 학기 초에 미리 올리는 방식이에요.
- 3곳은 자동 수집이 불가능하거나 확인이 안 됐어요. robots.txt로 수집을 막은 곳이 2곳, 접속 실패가 1곳이에요.
- 연도를 잘못 적은 사례가 1건 있었어요(아래 아주대). 자동으로 모아도 **사람 확인 단계가 필요해요.**

## 3. 알게 된 점
1. **대학마다 형식은 다르지만 "학위수여식"이라는 단어와 날짜가 같은 줄에 있는 경우가 대부분**이에요. 대학별 전용 수집기를 만들기보다, 공통 추출기(키워드 + 날짜 패턴) 하나로 대부분 처리할 수 있어 보여요.
2. **학부와 대학원 일정이 섞여 있어요.** 대학원 페이지가 검색에 먼저 걸리는 경우가 많아서, 대학별 "학부 학사일정 주소"를 사람이 한 번 정해줘야 해요.
3. **오기가 있어요.** 연도·요일 불일치는 자동으로 잡아낼 수 있어요(날짜와 요일 비교).
4. **수집을 막은 대학이 있어요.** robots.txt를 지키면 일부는 수동 입력으로 남겨야 해요.
5. 캠퍼스별로 날짜가 다를 수 있는데, 이번 표본에선 확인하지 못했어요.

## 4. 권장 방식: 반자동
1. **대학별 학사일정 주소 목록**을 만든다 (대학당 몇 분, 사람이 1회).
2. 주 1회 그 페이지 글자를 가져와 **'학위수여식' 줄과 날짜를 추출**한다 (robots.txt 준수).
3. **요일 검증·이전 값과 비교** → 바뀐 것만 표시.
4. **운영자가 확인한 날짜만 사이트에 반영**하고, 출처 주소와 확인일을 같이 저장한다.
5. 졸업생이 많은 대학 **50~100곳부터** 시작하고, 나머지는 사장님 직접 입력으로 둔다.

## 5. 다음 단계 제안
- 상위 대학 목록 정하기 (대학알리미 졸업자 수 기준이 좋지만, 데이터 확보가 필요해요)
- 위 7곳 날짜를 원본에서 확인한 뒤 사이트의 대학 데이터에 "학교 학사일정 기준"으로 먼저 넣어 보기
- 공통 추출기 시제품 만들기
