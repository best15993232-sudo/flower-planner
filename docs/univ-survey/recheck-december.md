# 대학 학위수여식: 12월 재확인 목록

정리일 2026-11-03 · 1차(클라우드)·2차(브라우저) 조사에서 날짜를 정하지 못한 곳이에요. **12월 첫 주에 다시 확인**해요(대부분 대학이 11~12월에 다음 해 1~2월 학사일정을 올려요).
2차 조사 5~7묶음(캠퍼스 120곳)은 11/3 밤에 모두 조사했고, 그중 확인 필요 38곳을 이 목록에 더했어요. 후보 82곳 중 77곳은 11/4 사이트에 반영했고, 5곳은 반영을 보류해 6번에 넣었어요. 2차 미처리는 없어요.

| 묶음 | 캠퍼스 수 |
|---|---:|
| 2026학년도 일정 아직 안 올라옴 | 97 |
| 날짜가 기간으로만 나옴(단과대별 행사) | 4 |
| 표기가 애매함(식 날짜인지 확인) | 11 |
| 분교·캠퍼스가 본교와 같은 날인지 | 4 |
| 사이트 문제(접속·파일·페이지 없음) | 11 |
| 후보였지만 반영 보류 | 5 |
| **합계** | **132** |

12월에 할 일: 1번은 같은 주소를 다시 열어 보기, 2·3번은 학교 공지(졸업식 안내)를 찾거나 학교에 문의, 4번은 분교 공지 확인, 5번은 다른 경로(학과 사이트·공지 게시판)로 찾기, 6번은 보류 이유만 확인.
