## 사이트 '의심 표시' 규칙에 대한 제안

1. **나이스 졸업식 날짜는 그대로 믿어도 됨.** 표본 43곳 불일치 0곳. 지금처럼 '등록' 표현을 쓰되, 졸업식 날짜에 일괄 경고를 붙일 필요는 없어 보입니다.
2. **의심 표시는 '날짜가 없거나 이상한 경우'에만** 붙이는 것을 제안합니다. 예: 나이스에 졸업식이 아예 없음, 같은 학교에 졸업식이 2개 이상, 겨울방학식보다 앞서거나 3월 이후 같은 비정상 날짜.
3. **학사일정 변경 안내가 많은 10~12월에는 '최근 변경 가능' 안내를 작게** 두는 정도면 충분합니다(마산가포고처럼 10월 말 변경 공지가 나오는 학교가 있음). 표본에서는 변경이 졸업식에 영향을 준 사례는 없었습니다.
4. 검증 규칙 보완 제안: 달력 종류가 haksa여도 행사명이 학교 고유 표기(예: '제76회 졸업식', '졸업식 및 종업식')면 학교 입력으로 볼 수 있습니다. 이번에는 README 규칙대로 haksa는 모두 '연동 의심'으로 적었습니다(18·20·43번 등).

## 진행 메모

- PDF는 컴퓨터에 내려받지 않고 브라우저 안에서 바로 읽거나(학교 문서뷰어 포함) 화면으로 확인했습니다. HWP/HWPX는 열지 않았습니다.
- 수동초(14) 재확인 때 학교의 '바로보기' 문서뷰어를 같은 창에서 열기 위해 뷰어 요청 양식(파일 주소만 담긴 것)을 한 번 보냈습니다. 개인정보나 입력값은 없었지만 '양식 제출 금지' 지시에 걸릴 수 있어 적어 둡니다.
- 사이트 코드(index.html)와 data/ 폴더는 바꾸지 않았습니다.
