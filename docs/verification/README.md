# 학교 졸업식 날짜 표본 검증 방법

목적: 나이스(NEIS) 졸업식 날짜가 학교가 직접 만든 자료와 얼마나 일치하는지 확인해 오류율을 낸다.

## 대상
- `sample.json`의 50곳 (지역·학교급·졸업 월이 섞이게 고정된 표본, 2026-10-29 선정)
- `results.csv`에 이미 있는 학교는 다시 보지 않는다. 단 결과가 `확인 불가`·`홈페이지 미등록`인 곳은 학사력 문서로 다시 시도해도 된다.

## 자료 우선순위 (B 방식)
1. **학교가 만든 1년치 학사력/학사일정표/교육과정 운영계획** 문서: 게시판(공지사항, 가정통신문, 학사일정)의 PDF·이미지 첨부 또는 본문
2. 졸업식 안내 가정통신문
3. 홈페이지 달력: 나이스와 행사명 표기가 다르면 학교가 직접 입력한 것으로 본다. 표기가 같거나 달력 종류가 '학사(haksa)'로 나이스 연동이 의심되면 `일치(연동 의심)`으로 적는다.
- HWP(한글) 파일은 열지 않는다. 대신 다른 자료를 찾거나 `확인 불가(HWP만)`로 적는다.
- 로그인이 필요하거나 수집이 막힌 페이지는 열지 않는다.

## 기록 (results.csv 한 줄씩 추가)
- `result`: 일치 / 불일치 / 일치(연동 의심) / 확인 불가 / 홈페이지 미등록
- `source`: 학사력 PDF / 학사력 이미지 / 가정통신문 / 홈페이지 달력 등
- `evidence`: 학교 자료의 날짜·행사명 원문, 자료 위치(게시판 이름, 게시일). 불일치면 학교 자료 날짜를 꼭 적는다.
- 학교 한 곳에 10분 넘게 쓰지 않는다.

## 끝나면
- 결과 요약(일치율, 불일치 학교 목록, 확인 불가 비율, 자료 유형별 개수)을 `summary.md`로 남긴다.
- 불일치 학교는 사이트 의심 표시 규칙에 반영할지 검토 메모를 남긴다.
