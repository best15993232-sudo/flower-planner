# 검색 노출 개선 계획 (언제 졸업해? · 오늘의 양재 꽃시세)

작성: 2026-11-20 · 대상: `flower-planner`(언제 졸업해?), `flower-sise`(오늘의 양재 꽃시세)

## 0. 왜 하나

- 두 사이트 모두 페이지를 연 뒤 휴대폰 안에서 목록·시세를 채우는 방식이라, 검색 로봇이 처음 받아 가는 글자에는 학교 이름·꽃 이름·가격이 거의 없어요.
- 구글·다음은 제목과 설명으로 두 사이트를 올렸지만(11/20 확인), 네이버는 아직 하나도 올리지 않았어요.
- 네이버 상위에 나오는 곳(하우팜, 팔레트, 원비히어, 학교 홈페이지)은 모두 **표와 글이 처음부터 글자로 들어 있는 페이지**예요.
- 그래서 지금 화면은 그대로 두고, **검색으로 들어오는 사람을 위한 글자 페이지(입구)를 자동으로 만들어** 검색어가 걸릴 곳을 늘려요.

## 1. 공통 원칙 (정한 것)

- **지금 쓰는 메인 화면은 그대로**예요. 모양·버튼·쓰는 방법을 바꾸지 않아요.
- **연결 방식 1번**: 메인에서 새 페이지로 가는 링크는 넣지 않아요. 새 페이지는 사이트맵과 검색으로만 들어와요.
  - 새 페이지에서 메인으로 가는 길은 항상 있어요: 맨 위 로고, 큰 버튼, 맨 아래 하단.
  - 나중에 메인에 작은 링크 한 줄만 더하면 2번(살짝 연결)으로 바꿀 수 있어요.
- 새 페이지는 **지금 사이트와 같은 디자인**(빈티지 압화 색, 글꼴)이에요.
- **숨긴 글자, 같은 말 반복, 날짜만 다른 똑같은 페이지 대량 생성은 하지 않아요.** 검색엔진이 벌점을 줘요.
- 모든 페이지에 **기준 날짜를 글자로** 붙여요(예: "11/20(금) 양재 경매 기준", "나이스 학사일정 기준"). 검색 결과에 옛 글자가 남아도 언제 정보인지 알 수 있게 해요.
- 설명 문구(검색 결과 아래 회색 글)에는 가격·날짜 숫자를 넣지 않아요. 바뀌는 숫자가 오래 남아 오해를 만들기 때문이에요.
- 매일 자동 작업이 페이지를 다시 만들어요. **내용이 바뀐 페이지만** 저장해서 저장소가 무거워지지 않게 해요.

## 2. 언제 졸업해? (flower-planner)

### 2-1. 새로 만드는 페이지

| 페이지 | 개수 | 예시 제목 | 들어가는 내용 |
|---|---|---|---|
| 시·군·구 졸업식 페이지 | 약 250 | 성남시 분당구 졸업식 날짜 2027 · 초·중·고 46곳 | 학교급별 표(학교 이름, 졸업식 날짜·요일, 졸업생 수), 날짜별 몇 곳인지 요약, 날짜 미정 학교 목록, 그 지역 대학 학위수여식 |
| 시·도 요약 페이지 | 17 | 경기도 졸업식 날짜 2027 · 학교급별 최다일 | 시·군·구별 학교 수와 가장 많은 졸업식 날짜, 시·군·구 페이지 링크 |
| 전국 요약 페이지 | 1 | 2027 졸업식 날짜 전국 정리 · 초·중·고·대학 | 월별·학교급별 학교 수, "초등학교는 1월 ○일에 가장 많아요" 같은 요약, 시·도 링크 |

- 구가 있는 시(수원·성남·고양 등)는 구 단위로 나눠요.
- 각 페이지 맨 위에 로고, 아래에 **"우리 가게 주변 학교로 보기 →"** 큰 버튼(메인으로 이동)을 둬요.
- 같은 시·도의 다른 시·군·구 링크를 아래에 넣어요(새 페이지끼리는 서로 연결).
- 학교 공지로 고친 날짜(과천고 등)는 "학교 공지 확인"으로 그대로 보여 줘요.
- 하단에 "날짜는 학교 사정으로 바뀔 수 있어요. 학교 공지를 꼭 확인해 주세요."와 출처(나이스, 학교알리미)를 넣어요.

### 2-2. 메인 화면에서 바뀌는 것

- 화면은 그대로예요.
- 제목·설명 문구만 검색어에 맞게 다듬어요(지금: "언제 졸업해? · 2027 우리 동네 졸업식").
- 11/20에 한 것: 첫 화면 부제를 "전국 학교 졸업식 날짜를 한눈에"로 바꿈(다음 검색 설명용), 구글 사이트 이름을 "꽃집을 위한 사이트"로 지정.

### 2-3. 노리는 검색어

| 묶음 | 예시 | 어디에 |
|---|---|---|
| 큰 말 | 졸업식 날짜, 2027 졸업식, 졸업식 일정, 학교 졸업식 언제 | 전국 요약 페이지, 메인 제목 |
| 학교급 | 초등학교 졸업식 날짜, 중학교 졸업식, 고등학교 졸업식 2027, 대학교 학위수여식 일정 | 전국·시도 페이지 소제목 |
| 지역 | 분당 졸업식 날짜, 수원 고등학교 졸업식, 대전 초등학교 졸업식 | 시·군·구 페이지 제목·표 |
| 꽃 관련 | 졸업식 꽃다발 준비, 졸업식 꽃 시즌 | 전국 요약 페이지 한 줄 + 꽃시세 행사 페이지로 연결 |

### 2-4. 만드는 방법

- 매일 새벽 데이터 갱신(`update-data`) 마지막에 페이지 만드는 스크립트를 한 번 더 돌려요.
- 사이트맵(`sitemap.xml`)에 새 페이지를 모두 넣고, 내용이 바뀐 날을 같이 적어요.
- 페이지 안 "마지막 변경일"은 그 지역 날짜가 실제로 바뀐 날만 바꿔요(매일 바뀌는 확인일은 넣지 않음).

### 2-5. 생길 수 있는 문제

| 걱정 | 막는 방법 |
|---|---|
| 졸업식 날짜가 바뀌었는데 검색 결과에 옛 날짜 | 페이지는 매일 새로 만들고, "학교 사정으로 바뀔 수 있어요" 안내를 모든 페이지에 넣음 |
| 학교가 적은 지역(울릉군 등) 페이지가 빈약 | 최소 학교 수 기준을 두고, 적은 곳은 시·도 페이지에 함께 보여 줌 |
| 메인 속도 | 메인은 바뀌지 않아 영향 없음 |
| 개인정보 | 학교 공개 정보만 쓰고, 이용자 정보는 넣지 않음 |

## 3. 오늘의 양재 꽃시세 (flower-sise)

### 3-1. 메인 화면에 미리 넣기

- 매일 시세 파일(`data/snapshot.json`)을 만드는 자동 작업(`snapshot.yml`)에서, **주요 품목 표를 메인 페이지 안에 글자로 미리 써 넣어요.**
- 화면 모양은 그대로이고, "불러오는 중" 대신 표가 바로 보여요. 더 새 시세가 있으면 지금처럼 "새 시세가 올라왔어요"로 알려요.
- 경매가 없는 날(일요일·명절)에는 '오늘' 대신 "최근 경매일 11/18(수)"로 써요.

### 3-2. 새로 만드는 페이지

| 페이지 | 개수 | 예시 제목 | 들어가는 내용 |
|---|---|---|---|
| 꽃별 시세 페이지 | 약 60~80 | 장미 경매 시세 · 오늘의 양재 꽃시세 | 품종·등급별 평균·최고·최저가, 거래량, 지난주 대비, 4주 흐름 그래프, 비슷한 꽃 링크 |
| 주간 시세 정리 | 매주 1개씩 쌓임 | 11월 3주 꽃 시세: 장미 ▲12%, 국화 ▼5% | 많이 오른·내린 꽃, 주요 품목 표, 다음 주 행사 |
| 행사 페이지 | 5~6 | 어버이날 카네이션 시세 · 해마다 흐름 | 행사 전후 가격 흐름, 준비 시기 안내 |
| 자주 묻는 질문 | 메인 아래 접힌 칸 1곳 | 경매가와 도매가 차이는? | 짧은 질문·답 5~8개 |

- 꽃별 페이지는 **최근 4주 거래량이 일정 이상인 품목만** 만들고, 나머지는 "기타 품목" 한 페이지에 모아요.
- 꽃 이름은 두 가지를 같이 써요: 리시안셔스(리시안사스), 안개꽃(안개), 튤립(튜립), 알스트로메리아(알스트메리아) 등.
- 각 페이지에서 메인으로 가는 길: 맨 위 로고, "전체 꽃 시세 보기 →" 버튼, "관심 꽃에 담기"(메인으로 가면서 그 꽃을 담음), 맨 아래 하단.
- 모든 페이지에 "경매 낙찰가예요. 소매가·도매상 판매가와 달라요."와 출처(aT 화훼유통정보시스템, 양재 화훼공판장)를 넣어요.
- 졸업·입학 행사 페이지는 '언제 졸업해?' 전국 요약 페이지와 서로 연결해요.

### 3-3. 노리는 검색어

| 묶음 | 예시 | 어디에 |
|---|---|---|
| 큰 말 | 꽃 시세, 꽃값, 화훼 경매 시세, 꽃 경매 시세, 절화 시세, 절화 경매가, 양재 꽃시장 시세, aT 화훼공판장 경매, 꽃 도매가 | 메인 제목·설명·첫 문단 |
| 꽃 이름 | 장미 시세, 안개꽃 가격, 카네이션 도매가, 거베라 경매가 | 꽃별 페이지 |
| 품종 | 하젤 장미, 프리덤 장미 시세, 레드나오미 | 꽃별 페이지 안 품종 표(품종마다 페이지는 만들지 않음) |
| 계절·행사 | 어버이날 카네이션 시세, 졸업식 꽃값, 밸런타인 장미 가격, 스승의날 꽃 가격 | 행사 페이지 |
| 이번 주 흐름 | 이번 주 꽃값, 꽃값 오른 이유, 11월 꽃 시세 | 주간 정리 페이지 |
| 궁금증 | 장미 한 단 몇 송이, 경매가와 도매가 차이, 꽃 경매 시간 | 자주 묻는 질문 |

### 3-4. 생길 수 있는 문제

| 걱정 | 무슨 일이 생기나 | 막는 방법 |
|---|---|---|
| 검색 결과에 옛 가격 | 네이버는 가져간 날의 글자를 며칠~몇 주 보여 줌 | 가격 옆에 항상 경매일, 설명 문구에는 숫자 안 넣음 |
| 화면 깜빡임·숫자 바뀜 | 미리 넣은 표 뒤에 새 시세가 오면 숫자가 바뀜 | 미리 넣는 표를 지금 화면과 같은 모양으로, 새 시세는 지금처럼 알림으로 |
| 경매 없는 날 | 지난 경매 가격이 오늘 시세처럼 보임 | "최근 경매일"로 표기 |
| 홈 화면 앱의 옛 화면 | 저장된 옛 페이지가 보일 수 있음 | 확인 결과 지금 `sw.js`는 저장 없이 항상 새로 받음. 그대로 유지 |
| 저장소가 무거워짐 | 꽃 페이지를 매일 다시 저장하면 기록이 쌓임 | 바뀐 페이지만 저장하거나, 배포할 때만 만들어 올리는 방식으로 변경 |
| 내용 적은 페이지 | 사이트 전체 점수가 깎임 | 거래량 기준 이상만 페이지 생성 |
| 가격 오해 | 경매가를 소매가로 착각 | 페이지마다 경매 낙찰가 안내 |

## 4. 진행 순서

| 단계 | 언제 졸업해? | 꽃시세 | 기간 |
|---|---|---|---|
| 1 | 전국 요약 페이지 + 시·군·구 페이지 1곳(성남시 분당구) 시안 → 사장님 확인 | 메인 제목·설명, 꽃 이름 두 표기, 메인 표 미리 넣기 | 1~2일 |
| 2 | 시·군·구·시도 페이지 전체 자동 생성, 사이트맵 | 꽃별 페이지 1개(장미) 시안 → 확인 → 전체 자동 생성, 사이트맵 | 2~3일 |
| 3 | 꽃시세 졸업·입학 행사 페이지와 서로 연결 | 주간 정리·행사 페이지, 자주 묻는 질문 | 2일 |
| 4 | 네이버 블로그·스마트스토어 공지에 사이트 소개 글과 링크(사장님, 초안은 Claude) | 매주 주간 정리 요약을 블로그에 올리기 | 매주 |
| 5 | 4주 뒤 서치 콘솔·서치어드바이저에서 실제로 들어온 검색어 확인 후 보강 | 같음 | 한 달 뒤 |

## 6. 확인 방법

- 구글: 서치 콘솔 '페이지'(색인 수), '실적'(들어온 검색어)
